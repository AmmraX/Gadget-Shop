# 💻 Gadget Shop
**Electronics Retail & Inventory Management System**

Gadget Shop is a robust management application designed to handle the daily operations of an electronics retail store. This project focuses on inventory accuracy, transactional integrity, and a structured approach to retail data management.

---

### ⚙️ Core Functionality
- **Inventory Control:** A centralized system to track electronic components and devices across multiple categories.
- **Transaction Processing:** Algorithmic calculation of sales, taxes, and discounts with digital receipt generation.
- **Stock Automation:** Real-time updates to stock levels following every transaction to prevent overselling.
- **User Authentication:** Secure access levels for staff to ensure sensitive inventory data is protected.

### 🛠 Technical Specifications
- **Programming Language:** Javascript, CSS, html, C#, ASP.net
- **Database Engine:** MySQL
- **Systems Design:** Focused on Data Persistence and Relational Mapping

---

### 📂 Project Structure
- **/src:** Contains all source code files including the main logic and database connectivity.
- **/database:** Includes the SQL schema scripts required to initialize the Gadget Shop database.
- **/docs:** Technical documentation regarding system requirements and setup.
